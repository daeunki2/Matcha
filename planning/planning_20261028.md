# Week 1 Goals

Implement sign-up and login functionality.

## Sign-up
page : creat account > register
**Front → Back**

- Request method and path: `POST /api/auth/register` 
filed : Description - Type
- First name : first_name - String
- Last name : last_name - String
- Username : user_name - String
- Email : email - String
- Password : password - String

**Back → Front**

- HTTP status + JSON `message`
- `202`: Request received. Please check your email.
- `400`: Please check your input.
- `500`: Unable to process your request. Please try again later.

Note: For an email address that is already registered, return the same 202 response as a new registration. Do not reveal whether the email address exists or expose internal error details.

## Email Verification

**Front → Back**
Create Account → Register → Send Email → Click Verification Link → Open Verification Page (URL with token) → Verify Email

Frontend page URL: /verify-email?token={token}

- Request method and path: `POST /api/auth/verify-email`

Field: Description - Type
- Verification token: `token` - String


**Back → Front**

- HTTP status + JSON `message`
- `200`: Your email has been verified successfully.
- `400`: Invalid verification request.
- `500`: Unable to process your request. Please try again later.

**Note:** The backend validates the token, checks its expiration and usage status, and updates the user's verification status in the database. The frontend is responsible for extracting the token from the verification link and displaying the result.
