# Week 1 Goals

Implement sign-up and login functionality.

## Sign-up

front > back

- First name
- Last name
- Username
- Email
- Password

back > front
- a code and message. 
- `202`: Request received. Please check your email. (Includes duplicate accounts.)
- `400`: Please check your input.
- `500`: Unable to process your request. Please try again later.


## Login

The frontend should send the following information to the backend:

- Email
- Password
